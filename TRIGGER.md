# Product Trigger

Build an institution-independent Cosmic Econometric Observatory: a versioned academic world engine in which programs become observatories, curriculum versions become universes, semesters become progress rings, courses become star systems, topics become planets, laboratories become research stations, and provenance sources become evidence satellites.

## Non-negotiable invariants

1. `Course ≠ CurriculumRelation ≠ Offering`.
2. Codes are versioned labels, not persistent identity.
3. Raw evidence is immutable; normalization is explicit and traceable.
4. The graph compiles to renderer-neutral Scene IR.
5. Identical catalog + graph + layout version + seed produces identical canonical output.
6. 3D, SVG, HTML and screen-reader projections consume the same Scene IR.
7. Canvas is enhancement, never the only way to inspect or navigate knowledge.
8. RASAT may eventually emit only allow-listed structured commands; never executable renderer code.
