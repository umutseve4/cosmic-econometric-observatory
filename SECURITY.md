# Security Policy

## Scope

This repository publishes a static GitHub Pages application and CI-generated evidence. Security-sensitive areas include dependency integrity, workflow permissions, artifact provenance, public-site verification, and any script that processes external content.

## Reporting

Use GitHub's private vulnerability reporting feature if it is available for this repository. If no private channel is available, open a minimal public issue requesting a private coordination channel.

Do not include exploit instructions, credentials, tokens, personal data, or sensitive evidence in a public issue. Maintainers should acknowledge a report before requesting additional sensitive details.

## Supported version

Security fixes target the current `main` branch. Historical branches and retained evidence are not supported releases unless explicitly stated.
